# Workbench

This project connects to a shared knowledge-base repository through the installed `oversoul`
skill. Register the target in this workbench's ignored `.linked-repos.json`, then use
`/oversoul` (Claude Code), `$oversoul` (Codex), or the Copilot Oversoul prompt to inspect status
and operate against it. See `workbench-adapters/oversoul/README.md` (or the installed skill's
own README) for the registration format and client commands.
